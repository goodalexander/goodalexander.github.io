Company model API

Unlimited reads of accepted company models for $200 per month, metered and rate-limited. Model responses include the exact version and source date.

Documentation

Base URL: https://api.corbanu.com. Use your Corbanu key in the Authorization: Bearer header. Never put a key in a URL, page or public notebook.

  1. Use the existing Corbanu account checkout to fund your prepaid API balance and obtain a key. This newsletter form does not issue keys.
  2. Read GET /v1/company-model-plan for the current monthly quote. Purchase one month with POST /v1/company-model-subscription, your authorization header, and X-Corbanu-Confirm-Monthly-Usd set to the exact quoted monthlyUsd. This debits your existing balance once. Renewal is explicit.
  3. Read GET /v1/company-models for accepted model IDs, then GET /v1/company-models/TSLA/outputs. Check GET /v1/company-model-subscription for expiry and your metered call count.

No per-read charge and no monthly call cap. Launch limit: 10 successful reads per rolling minute per account, shared across keys. A refused call is not counted. Source dates older than seven days, withheld outputs and failed model checks are refused.

Responses: 401 invalid/missing key; 402 subscription or balance required; 409 withheld/stale model or duplicate request ID; 429 rate limited; 503 source unavailable. Respect Retry-After. Supplied request IDs must be unique per call. Data is filtered to first-party model forecasts and targets; third-party data and trading-performance fields are excluded.
